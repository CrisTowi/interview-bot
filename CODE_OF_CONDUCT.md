# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be patient with people who are learning (many of them are preparing for interviews that matter to them), give feedback about code rather than people, and assume good faith.

To report unacceptable behavior, contact the maintainer privately through a [GitHub security advisory](https://github.com/CrisTowi/interview-bot/security/advisories/new) or by direct message on GitHub ([@CrisTowi](https://github.com/CrisTowi)). Reports are kept confidential.
